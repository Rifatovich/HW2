# Домашнее задание №2: выделение границ

Сравнение операторов Собеля, Щарра, Прюитта и детектора Кэнни после медианной и гауссовой фильтрации на трёх УЗИ и одном КТ с почками. Маски сегментации используются только для сравнения и оценки.

## Запуск

```
python -m pip install -r requirements.txt
python solution.py
```

Положите `hw2.zip` рядом с `solution.py` или распакуйте его в папку `hw2`. Скрипт сам распаковывает архив, если папки `hw2` ещё нет. Изображения читаются в градациях серого.

## Параметры

Одинаковые для всех снимков.

- Медианный фильтр 7×7.
- Гауссов фильтр 7×7, σ=1,5.
- Sobel, Scharr, Prewitt: модуль градиента, нормализованный по 99-му перцентилю, чтобы яркий край УЗИ-сектора не гасил остальное.
- Canny: верхний порог равен 92-му перцентилю градиента снимка, нижний 0,4 от верхнего, `L2gradient=True`.

## Результаты

Функция `process_image` принимает изображение и возвращает 8 результатов: 2 фильтра × 4 оператора.

В `results/img_XXXXXX/` для каждого снимка сохраняются 8 изображений вида `median_sobel.png` и `comparison.png`. В сравнении сверху исходник и маска, затем строка median и строка Gaussian.

В консоль выводится таблица с долей границ около контура почки. Это грубая метрика для ориентира, вывод сделан по визуальному сравнению.

## Вывод

На УЗИ однозначно лучшей комбинации нет. Sobel, Scharr и Prewitt дают практически одинаковые карты: виден внутренний рисунок почки, но самый яркий отклик у края ультразвукового сектора, а по всему полю много откликов на спекл, поэтому контур почки теряется среди текстуры. Canny после median оставляет много коротких штрихов от спекла по всему сектору. Gaussian + Canny чище, лишних линий заметно меньше, и фрагменты границы почки в центре видны лучше, но контур разорван. На УЗИ она выглядит наиболее удачной, хотя полного замкнутого контура почки не даёт ни один вариант.

На КТ почки видны чётко почти во всех вариантах, так как контраст высокий. Sobel, Scharr и Prewitt показывают обе почки замкнутыми яркими контурами, но линии широкие и полутоновые. Наиболее удачной выглядит median + Canny: тонкие линии, контуры обеих почек хорошо прослеживаются, а тонкая дуга стола сверху, которая остаётся после Gaussian, убирается медианным фильтром. Во всех вариантах присутствуют границы других органов и позвоночника.

Median лучше сохраняет края и убирает импульсный шум, Gaussian сильнее сглаживает и размывает контуры. На УЗИ из-за спекла сглаживание помогает, на КТ с чистыми границами median даёт более чёткий результат.
